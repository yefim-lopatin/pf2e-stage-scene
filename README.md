# PF2e Stage Scene

Локальный модуль Foundry VTT для визуальных диалоговых сцен.

Возможности:

- портреты актёров и персонажей;
- фоны из файлов, видео или текущей сцены Foundry;
- музыка, атмосферные эффекты, частицы, параллакс и камера;
- сохранённые пресеты с фоном, персонажами и их расположением;
- экспорт и импорт пресетов для модулей приключений;
- синхронный показ сцены у игроков.

## Установка

Скопируйте папку `foundry-pf2e-stage-scene` в каталог `Data/modules` вашей установки Foundry VTT, включите модуль SocketLib и затем PF2e Stage Scene.

Для открытия используйте кнопку с театральными масками в левой панели управления сценой или макрос:

```js
window.openPF2eStageScene();
```

## Основа

Модуль создан на основе Player Queue 14.7.0 с разрешения автора. Очередь игроков, её макросы, звуки и интерфейс в эту версию не включены. Лицензия исходного кода сохранена в [LICENSE](LICENSE).
